# Exemples Détaillés de Termes Spécialisés

## abélien
- **Confidence**: 0.8
- **Sources**: wikipedia
- **Définition**: L'adjectif abélien, dérivé du nom du mathématicien norvégien Niels Abel, est employé dans de nombreux domaines des mathématiques.
En théorie des groupes,

un groupe abélien est un groupe dont la loi est commutative ;
un groupe métabélien (en) est un groupe dont le groupe des commutateurs est abélien ;
l'abélianisé d'un groupe est son plus grand quotient abélien.
- **Termes clés**: l'adjectif, abélien, dérivé, nom, mathématicien
